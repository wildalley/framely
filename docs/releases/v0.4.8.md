# Framely · 取景 v0.4.8 — 翻译、选段与错误恢复体验优化

改进截图到文字、翻译和 GIF 的操作流程，同时修复翻译传输、长行处理和录屏中断恢复问题。

v0.4.7 因 Windows 平台回归测试断言不兼容而未发布；本版修正该断言，并包含其全部改进。

## 主要变化

- **选区操作始终可达**：修复屏幕边缘的工具栏越界，窄屏使用「更多」菜单，保留保存、复制与取消。
- **翻译可取消、可恢复**：重试和失败保留上次译文及其原文、方向；配置入口直达翻译页，缺密钥、模型或地址无效时提供下一步操作。远端接口要求 HTTPS，阻止降级跳转，本机回环服务继续支持 HTTP。
- **离线长行不再截断**：按模型 token 分段处理并恢复原文顺序；模型下载与删除互斥，重试和排队任务可取消。
- **GIF 可视化选段**：增加指定时间的画面预览和双端时间轴，支持拖动、键盘与精确秒数输入。预览去抖、限时并取消旧任务；修复分片 MP4 重新打开后时长为零的问题。
- **OCR 与钉图键盘操作**：扫选靠近上下边缘自动滚动，释放后停止；Tab 可显示钉图操作栏，小图可使用菜单键或 Shift+F10。
- **错误反馈更直接**：设置校验在字段附近提示并定位页面；录屏中断后可打开保留片段或文件夹，播放与打开失败给出反馈，完整诊断可展开、复制。
- **高亮与采集更稳定**：缓存高亮遮罩几何，减少大量重叠高亮的计算；分离录屏与长截图会话，统一取消、文件保留、关闭采集源与图片交接。

## 下载与升级

| 平台 | 附件 |
| --- | --- |
| Windows x64 | `framely-0.4.8-windows-amd64-setup.exe`、`framely-0.4.8-windows-amd64-portable.zip` |
| macOS 15+ Apple Silicon | `framely-0.4.8-darwin-arm64.dmg` |
| macOS 15+ Intel | `framely-0.4.8-darwin-amd64.dmg` |
| Ubuntu / Debian x64 | `framely-0.4.8-linux-amd64.deb` |
| Arch Linux x64 | `framely-0.4.8-1-x86_64.pkg.tar.zst` |
| Linux x64 便携版 | `framely-0.4.8-linux-amd64-portable.tar.gz` |

完整包包含采集、媒体和离线 OCR 组件，无需另装 Go、Python 或 FFmpeg；离线翻译模型仍在设置中按需下载。发布页提供七个附件的 `SHA256SUMS`。

升级前从托盘退出旧实例，再更新完整发行包。已有远端 HTTP 翻译地址需改为 HTTPS；本机 `localhost` 与回环 IP 地址可继续使用 HTTP。配置、已保存的密钥和翻译模型会保留。

## 验证范围

本地通过 Go 源码包竞态测试、静态检查、Python 脚本回归、内置媒体组件的分片视频与指定时间预览检查，以及 MyGo 控件的窄窗口、明暗主题和键盘交互检查。发布工作流重新构建四个平台的原生组件与应用、生成 Arch 包，并检查全部附件后发布。

原生门户授权、多显示器操作、长时录屏和目标平台真机使用仍需按设备验收。Windows/macOS 安装包尚未配置正式开发者签名与公证。
