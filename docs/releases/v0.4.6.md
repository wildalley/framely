# Framely · 取景 v0.4.6 — 修复 Windows 安装迁移报错

修复 Windows 安装器提示「Framely was installed, but migration failed」，并报告注册表不存在 `io.screenpin.desktop` 属性的问题。

## 主要变化

- **未配置自启动也能正常升级**：读取旧自启动设置时，允许注册表值不存在，继续完成快捷方式迁移和旧组件清理。
- **保留自启动选择**：未配置自启动时不会新增启动项；已有但被禁用的自启动仍保持禁用。
- **安装器回归检查**：增加 ScreenPin 旧目录迁移和 Framely 原目录升级在未配置自启动时的场景，同时检查重复安装。

## 下载与升级

| 平台 | 附件 |

| Windows x64 | `framely-0.4.6-windows-amd64-setup.exe`、`framely-0.4.6-windows-amd64-portable.zip` |

完整包包含采集、媒体和离线 OCR 组件；离线翻译模型在设置中按需下载。发布页提供全部七个附件的 `SHA256SUMS`。

升级前请从托盘退出旧实例。Windows 用户若之前遇到迁移报错，可使用本版安装器再次安装，无需手动创建自启动注册表项。Linux 便携版需执行 `./install.sh`，macOS 替换应用程序目录中的 `Framely.app`。
