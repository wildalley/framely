# Framely · 取景 v0.3.0 — 区域录屏、快捷操作与 MyGo 0.8.3

原 ScreenPin 现以 Framely · 取景发布。本版升级至 MyGo 0.8.3，带来区域录屏、GIF 导出、新折纸 F 图标和更直接的工具栏流程。

## 下载与升级

| 平台 | 附件 |
| --- | --- |
| Windows x64 | `framely-0.3.0-windows-amd64-setup.exe`、`framely-0.3.0-windows-amd64-portable.zip` |
| macOS 15+ Apple Silicon | `framely-0.3.0-darwin-arm64.dmg` |
| macOS 15+ Intel | `framely-0.3.0-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `framely-0.3.0-linux-amd64.deb` |
| Arch Linux x64 | `framely-0.3.0-1-x86_64.pkg.tar.zst` |
| Linux x64 便携版 | `framely-0.3.0-linux-amd64-portable.tar.gz` |

完整包包含屏幕采集、录屏/FFmpeg、离线中英文 OCR 模型和运行时。`SHA256SUMS` 提供全部七个附件的校验值。升级前从托盘退出旧实例，完整替换应用与配套组件。安装包和 Arch 包改用 `framely` 名称，命令、配置目录及桌面/门户 ID 仍沿用 `screenpin`，已有设置与授权保留；Arch 包自动替换 `screenpin-native`。

Windows/macOS 的应用名称和路径会变化；如果系统仍保留指向旧 ScreenPin 路径的启动项或自定义快捷方式，请重新配置。

## 主要变化

- **MyGo 0.8.3**：升级原生 GUI 框架，纳入上游裁剪遮罩内存预算、动画纹理回收和 Linux 点击穿透等修复；保持既有输入取消兼容处理。
- **区域录屏**：30/60 fps 目标帧率，最高 720p/1080p/1440p/4K，录制无声 MP4；支持暂停、恢复、结束并保存，以及录完预览。
- **减少重复操作**：框选后进入原截图工具栏，一击进入长截图、录屏或识别文字；录屏直接沿用本次选区。再次录制可沿用上次区域，显示器位置、帧率和分辨率在重启后保留；另有“重新选区”入口。
- **GIF 导出**：选择任意 MP4，按起点、时长、帧率和宽度导出；显示进度，可取消，不覆盖原视频。
- **默认保存**：自动保存到系统“视频/Framely”，可修改目录或改回每次询问；同名文件自动编号。
- **录制控制**：选区外侧浮动控制条与托盘显示计时、暂停/恢复及结束；独立录屏快捷键或 `screenpin --record` 在录制中再次执行会结束保存。
- **多屏与托盘**：Linux 录屏补齐显示器坐标，按屏恢复共享授权，错屏恢复会重新选择；快捷键显示规范化，托盘菜单原地更新，避免菜单展开时重复重建。
- **新图标**：深青底、暖白折纸 F 与橙色折角；应用、界面标记、单色托盘和录制角标同步更新，SVG 母版可复现生成全部 PNG。
- **性能与构建**：长截图预览复用有界双缓冲，单次更新分配从约 2.26 MiB 降至 96 B；录屏首次组件检查在后台执行。媒体源码下载支持有界重试，半成品不进入有效缓存。

## 验证与范围

源码竞态/静态检查、图片关闭与预览缓冲回收、UI 布局、隔离门户和媒体 MP4/GIF 回归已经覆盖。80 次软件图片关闭及 60 次原生窗口生命周期检查没有出现持续的资源增长；3600 帧软件编码压力检查保持稳定。数值与边界见 [资源检查](../AUDIT_2026-11-11.md)，不代表排除所有 GPU/驱动泄漏。

- 当前录制无声视频；不采集系统声音或麦克风。
- 60 fps 为目标值，实际采集帧率和编码器取决于桌面、来源、显卡与驱动。优先硬件 H.264，不可用时回退软件编码。
- Linux 的系统屏幕共享授权仍需用户完成；工具栏复用区域不能绕过系统授权。Linux 控制窗需位于录制区域外。
- macOS 暂不支持长截图。Windows/macOS 尚未配置正式开发者签名与公证。
- 数小时硬件录屏、各种混合 DPI 多屏环境和各平台实际桌面权限仍需实机验收。自动构建通过不等于所有交互均已完成真机验证。
