# ScreenPin v0.2.2 — 离线取字、选词复制与资源管理优化

本次更新改善离线 OCR 和长截图流程，加入“大爆炸”式选词复制，减少长截图像素传输，并补齐图片内存预算与发布校验。也包含此前 v0.2.1 标签中的工具栏、属性栏、托盘和多显示器截图改进；v0.2.1 未完成正式 Release 发布。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `screenpin-0.2.2-windows-amd64-setup.exe`；免安装版 `screenpin-0.2.2-windows-amd64-portable.zip` |
| macOS 15+ Apple Silicon | `screenpin-0.2.2-darwin-arm64.dmg` |
| macOS 15+ Intel | `screenpin-0.2.2-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `screenpin-0.2.2-linux-amd64.deb`（Ubuntu 22.04 或兼容运行库） |
| Arch Linux x64 | `screenpin-native-0.2.2-1-x86_64.pkg.tar.zst` |
| 其他 Linux x64 | `screenpin-0.2.2-linux-amd64-portable.tar.gz` |

完整包内置离线中英文 OCR 模型与运行时，无需安装 Python，不上传截图或在运行时下载模型。`SHA256SUMS` 提供全部七个安装包与便携包的校验值。升级前请退出旧实例，并完整替换主程序和配套组件。

## 主要变化

- **直接框选取字**：从托盘“框选取字…”或 `screenpin --ocr` 开始；识别过程中显示逐块进度，连续识别复用模型，空闲后回收进程。
- **“大爆炸”式选词**：中文分词并保留网址、邮箱和数字；支持点击、拖动连续选择/取消、Shift 连选、单字模式、键盘操作和全文编辑复制。
- **区域 OCR**：选区识别保留标注、马赛克和圆角效果；排队后才合成所需区域，减少多窗口同时识别时的内存峰值。
- **长截图效率**：Linux 与 Windows 在采集组件内裁剪选区后传输，保留显示器原始坐标；减少大屏幕采集的复制与分配，复用拼接计算缓冲。
- **资源管理**：统一图片读取和尺寸限制，增加多窗口图片估算预算与撤销历史字节预算；长截图提前预留结果额度，取消、关闭与后台任务结束后释放持有资源。
- **工具栏与托盘**：更新标注属性控件、颜色与圆角调整、高清托盘图标和“一键关闭全部贴图”；改善 Windows 内存截图及 Linux 多显示器长截图流程。
- **构建与安全**：修复 Arch 版本漂移和 Windows OCR 测试清理问题；增加完整附件校验、构建依赖哈希锁、组件源码一致性检查、Python 依赖清单及定期依赖扫描。

当前主线已清理停用的 Tauri/React 源码、依赖清单与旧 CI；历史版本仍可通过 `v0.1.1` 标签查阅。README 的快捷键、平台能力与构建步骤已按原生版更新。

## 平台与功能范围

- macOS 支持截图、贴图、标注与离线 OCR，暂不支持长截图。
- Windows/macOS 安装包尚未配置正式代码签名与公证；平台首次运行提示取决于系统设置。
- OCR 暂不重建复杂多栏和表格文档结构；原图文字框联动、拖动选词时的边缘自动滚动尚未实现。
- 图片预算是应用内部的工作集估算，不是进程 RSS 或 GPU 内存硬上限。本轮完整安装包体积没有显著下降。

详细实现与测试范围见仓库中的 `docs/OCR_WORKFLOW.md` 和 `docs/AUDIT_2026-11-10.md`；真实桌面的混合 DPI、持续采集资源占用等验收继续跟踪在 `IMPROVEMENTS.md`。
