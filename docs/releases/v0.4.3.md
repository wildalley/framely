# Framely · 取景 v0.4.3 — 长截图修复、录屏控件与预览优化

本版修复固定菜单栏参与长截图时的重复和竖向拖影，统一录屏控制条与应用界面风格，并减少长截图预览的临时内存分配。

## 主要变化

- **固定侧栏长截图**：正文按滚动距离拼接，识别出的左右固定侧栏原图只保留一次，新增高度填充侧栏背景；不会再把底部头像或文字像素拉成长条，截图宽度保持不变。
- **长截图控件**：选区边框不拦截鼠标；空间足够时在采集区域外显示独立实时预览，暂停、撤回、完成及关闭同步状态并清理浮层。空间不足时使用托盘或快捷键控制。
- **录屏控制条**：使用暖白/深灰底、深青主按钮与橙色录制标记；计时、状态和暂停/继续、结束按钮保持稳定位置，修正圆角透明区域和按钮提示残影；增加录制区域边框。
- **界面一致性**：统一设置、取字/翻译、钉图、标注属性与选区操作栏的边框、间距和按钮分组。
- **内存与性能**：侧栏缓存只保存侧栏像素，不再额外保留首张整帧；缩略图使用按值像素采样路径，逐像素对照原缩放结果验证一致。

本机 Linux 基准中，缩略图每次临时分配约 **10.8 MB → 2.16 MB**，耗时约 **32 ms → 20 ms**。80 次软件图片生命周期、120 次原生窗口循环未见持续增长的像素缓冲、文件描述符或 goroutine。测量条件、命令和验证边界见 [资源检查报告](../AUDIT_2026-11-12.md)。

完整包包含采集、媒体与离线 OCR 运行时；离线翻译模型仍在设置中按需下载。发布页提供 `SHA256SUMS` 校验全部七个安装/便携附件。

升级前请从托盘选择「退出 Framely」，再完整安装新版及配套组件。仅关闭窗口不会退出后台实例；新版启动时可能将操作交给仍在运行的旧版。若重开仍显示旧版本，检查菜单、自启动或快捷键是否指向另一份便携/开发安装。Windows 使用安装器执行迁移；Linux 便携版解压后执行 `./install.sh`；macOS 替换应用程序目录中的 `Framely.app`。配置迁移延续 [v0.4.2](v0.4.2.md)。

## 验证与限制

- 源码包竞态测试、静态检查、34 项 Python 脚本回归、版本一致性以及 Windows x64 / macOS arm64 Go 程序交叉编译通过；安装包和原生组件由目标平台 CI 构建、校验。
- 动态菜单、悬浮内容或无法可靠识别的布局仍建议只框选滚动正文。
- 录屏仍为无声 MP4，暂不采集系统声音或麦克风；macOS 暂不支持长截图。
- 未执行数小时硬件录屏或 Windows/macOS 真实桌面资源循环；交叉编译不等同于实机验收。
- Windows/macOS 安装包暂未配置正式开发者签名与公证。
