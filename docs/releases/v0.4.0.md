# Framely · 取景 v0.4.0 — 新界面、一次框选多种操作与翻译

本版按新图标重做界面，框选后不用再重复选区，并新增取色器、重复上次区域和翻译（在线服务或按需下载的离线模型）。

## 下载与升级

| 平台 | 附件 |
| --- | --- |
| Windows x64 | `framely-0.4.0-windows-amd64-setup.exe`、`framely-0.4.0-windows-amd64-portable.zip` |
| macOS 15+ Apple Silicon | `framely-0.4.0-darwin-arm64.dmg` |
| macOS 15+ Intel | `framely-0.4.0-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `framely-0.4.0-linux-amd64.deb` |
| Arch Linux x64 | `framely-0.4.0-1-x86_64.pkg.tar.zst` |
| Linux x64 便携版 | `framely-0.4.0-linux-amd64-portable.tar.gz` |

完整包包含屏幕采集、录屏/FFmpeg、离线中英文 OCR 及其运行时；离线翻译模型不在安装包内，需要时在设置中下载。`SHA256SUMS` 提供全部七个附件的校验值。升级前从托盘退出旧实例，完整替换应用与配套组件；离线翻译需要本版附带的新文字识别组件。命令、配置目录和桌面/门户 ID 不变，已有设置与授权保留。

## 主要变化

- **新界面**：配色改为图标的深青、暖白与橙色点缀。图片窗口改为顶部细栏、左侧竖排工具栏和画布，不再拆成两三行；窄窗口放不下的操作收进「More」，复制与关闭始终可见。最小窗口 480 × 360，小图居中。
- **样式面板**：选中标注或绘图工具时，在工具栏旁展开色点、细/中/粗、直角/小圆角/大圆角和不透明度，一点即用；精确数值在「更多…」。所选标注在面板下方时面板移到右侧。
- **无边框钉图**：钉住后只留图片和细橙色描边，位置不变；拖动移动、滚轮缩放、双击回到编辑，悬停显示编辑、复制、缩放和关闭。
- **一次框选，多种操作**：松开后选区仍可移动、拉伸、方向键微调。下方操作栏直接复制（Enter，不开窗口）、原位钉住（双击）、带工具进入标注、保存、长截图、录屏、取字或翻译。R 恢复上次区域，右键清除选区。
- **取色**：框选时放大镜显示像素、坐标和颜色值，按 C 复制 `#RRGGBB`；托盘「取色器…」或 `--color` 单独取色。
- **重复上次区域**：托盘或 `--repeat` 不用框选，按上次确认的区域再截一张。
- **翻译**：取字窗口新增「翻译」页，原文译文对照；托盘「框选翻译…」、操作栏「翻译」和 `--translate` 识别后直接翻译。
  - 在线：DeepL、百度翻译、腾讯翻译君或兼容 OpenAI 的大模型接口，填写自己的密钥，保存在系统密钥库；只发送识别出的文字，不发送图片。
  - 离线：中英互译模型（OPUS-MT，每个方向约 110 MB）在设置中点「下载」后才获取，逐文件校验 SHA-256，本机翻译不联网。离线译文质量低于在线服务。
  - 未设置翻译服务时不发送任何内容。
- **托盘**：按「开始任务 / 文字与颜色 / 图片 / 应用」分组；Linux 与 Windows 托盘改用新的彩色应用图标，录屏时加红色角标。

## 验证与范围

源码竞态与静态检查、界面布局、选区交互、翻译服务请求格式与签名（本地模拟服务）、模型下载校验与取消、离线翻译组件协议已经覆盖；离线模型从发布页实际下载并在本机翻译通过。4K 软件渲染下选区每次移动重绘约 3.7 ms；选区所有退出路径都释放整屏截图；编辑器 80 次与原生窗口 300 次循环没有持续增长。数值见 [资源检查](../AUDIT_2026-11-11.md)。

- 窗口吸附尚未实现：Wayland 不允许应用读取其他窗口位置。
- 取色器与重复上次区域需要 Framely 自有选区：Linux 需先允许直接截图，macOS 暂不支持。
- 多屏真实桌面的选区、HiDPI 与 Wayland 下钉图位置、各在线翻译服务的真实密钥尚需实机验收。
- macOS 暂不支持长截图。Windows/macOS 尚未配置正式开发者签名与公证。
