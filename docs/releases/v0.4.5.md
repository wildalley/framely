# Framely · 取景 v0.4.5 — 修复普通截图复制

修复框选普通截图后，点击「复制」或按 Enter，剪贴板仍保留旧图片的问题。

## 主要变化

- **普通截图复制**：先在框选窗口仍持有焦点时写入剪贴板，再关闭窗口，解决 Wayland 下接口返回成功但系统剪贴板未更新的问题。
- **取消与重复操作**：图片在后台编码，期间可按 Esc 取消；等待复制时冻结选区并阻止重复操作，取消后不再写入剪贴板。
- **减少中间处理**：直接复制无需再创建编辑图片、生成马赛克预览或重复编解码。
