# ScreenPin v0.2.0 — MyGo 原生版

使用 Go + MyGo 重制桌面界面。启动后在托盘待命，每张截图、粘贴或打开的图片独立开窗，关闭后释放图片及编辑记录。配置沿用旧版，原生版不再提供工程保存流程。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `screenpin-0.2.0-windows-amd64-setup.exe`；另有 portable ZIP |
| macOS 15+ Apple Silicon | `screenpin-0.2.0-darwin-arm64.dmg` |
| macOS 15+ Intel | `screenpin-0.2.0-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `screenpin-0.2.0-linux-amd64.deb`（Ubuntu 22.04 或更新运行库） |
| Arch Linux x64 | `screenpin-native-0.2.0-1-x86_64.pkg.tar.zst` |
| 其他 Linux x64 | `screenpin-0.2.0-linux-amd64-portable.tar.gz`，解压后运行 `./install.sh` 或 `./screenpin` |

完整包附带离线 OCR 模型与运行时，不需要用户安装 Python。安装前请退出旧版；Linux 原生包不需要 WebKitGTK。`SHA256SUMS` 包含所有附件的 SHA-256 校验值。

## 主要变化

- Windows/Linux 长截图：选择来源并框选滚动内容，支持自动或手动滚动、暂停、撤回与拼接预览。再次按全局截图快捷键完成。
- 本地中英文 OCR：整图/框选识别、长图分块、结果编辑及全文/逐行复制。关闭图片或取消会终止识别进程，不上传图片。
- 工具栏第二行直接调整颜色、圆角、粗细/字号、不透明度；矩形和整张截图支持独立圆角及撤销/重做。PNG/WebP 保留透明四角，JPEG 使用白底。
- 形状画完直接进入调整状态，四角及边缘均可缩放；笔刷仍支持连续绘制。
- 托盘菜单重新分组，设置与按键说明合并；窄窗口、深浅色及不同缩放比例的布局修复。
- PNG/JPEG/WebP 导出，JPEG/WebP 质量可调；透明图片和裁剪图片编码修复。
- Linux 门户授权和取消处理完善；niri 提供可确认、备份及回滚的快捷键配置，修复屏幕共享后端冲突诊断与线性 DMA-BUF 采集。

## 平台说明

- **macOS 本版支持截图、标注、圆角及离线 OCR，长截图尚未实现。** 提供 ad-hoc 签名的 DMG，尚未做 Apple 开发者签名及公证；首次打开可能需要在系统设置中允许。Windows 安装程序未做发布者代码签名。
- Wayland 自动滚动需要桌面的 RemoteDesktop 指针控制授权；当前 niri 使用手动滚动。niri 屏幕共享应由 `xdg-desktop-portal-gnome` 提供。
- Windows 自动滚动无法向权限更高的目标程序发送输入时，会暂停并允许改用手动模式。
- 自动化检查覆盖 Go 竞态/静态检查、UI 布局与输入、拼接、透明编码、隔离门户、原生缓冲区以及各平台打包后的真实离线 OCR。Linux 已在 niri 验证真实 4K 屏幕帧；安装包构建与 OCR 检查不代表三端桌面交互均已完成真机验收。
