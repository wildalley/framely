# ScreenPin v0.2.1 — 工具栏视觉重构与截图体验增强

本次更新重点重构了图片标注编辑器的工具栏与属性栏样式，重新绘制了系统托盘图标并增加了快捷贴图批量管理，同时对长截图和常规截图流程进行了大幅优化。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `screenpin-0.2.1-windows-amd64-setup.exe`；另有 portable ZIP |
| macOS 15+ Apple Silicon | `screenpin-0.2.1-darwin-arm64.dmg` |
| macOS 15+ Intel | `screenpin-0.2.1-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `screenpin-0.2.1-linux-amd64.deb`（Ubuntu 22.04 或更新运行库） |
| Arch Linux x64 | `screenpin-native-0.2.1-1-x86_64.pkg.tar.zst` |
| 其他 Linux x64 | `screenpin-0.2.1-linux-amd64-portable.tar.gz`，解压后运行 `./install.sh` 或 `./screenpin` |

完整包附带离线 OCR 模型与运行时，不需要用户安装 Python。安装前请退出旧版；Linux 原生包不需要 WebKitGTK。`SHA256SUMS` 包含所有附件的 SHA-256 校验值。

## 主要更新内容

### 1. 标注工具栏与属性栏样式全面重构
- **极简工具栏**：去除原有图标按钮的突兀灰底方块，采用扁平透明无框底，悬停与激活时使用主题色微强调，并以低对比度竖线进行逻辑分组（选择移动 / 基础图形 / 涂鸦 / 文本与特殊 / 操作）。
- **连体胶囊属性组件**：数值调节器（线宽、字号、圆角、不透明度）重构为现代一体化胶囊控件 `[ 标签 数值 | ▲▼ ]`；快捷比例切换重构为平铺胶囊段控件；取色器改为圆形药丸微拟态视觉。
- **底板衬底加持**：属性行采用统一的主题色微透明底板包裹，彻底消除上一版本控件参差错位感。

### 2. 系统托盘与贴图管理体验升级
- **全新高清托盘图标**：重绘半透明圆角底托、高对比白色取景器框与醒目橙色图钉，修复之前托盘图标模糊/隐形的问题。
- **动态状态悬停**：托盘鼠标悬停时动态显示已注册全局截图快捷键（如 `ScreenPin (Ctrl+Alt+A 截图)`）或长截图状态。
- **一键关闭全部贴图**：托盘菜单新增「关闭所有贴图 (N)」项，贴图窗口打开或关闭时自动动态刷新托盘计数。

### 3. 截图与长截图流程优化
- **全屏原生选区与内存采集**：Windows 截图改为自有全屏选区与纯内存采集，取消截图不再生成残留临时文件。
- **长截图流畅拼接**：Linux PipeWire 采集提升至 40ms，边滚边拼无需停顿；优化多屏及负坐标屏幕选区恢复。
