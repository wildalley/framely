# Framely · 取景 v0.4.4 — 长截图动画容错与自动滚动体验

本版改善带有局部动画的页面截图，减少短暂匹配失败造成的干扰，并让自动滚动设置更容易找到。

## 主要变化

- **局部动画容错**：将集中在小范围、变化明显的动画与整体滚动区分开，避免 GIF 更新被当成新增内容，或让自动模式一直等待。保留稀疏表格、重复内容及整页动态变化的保守判断。
- **对齐提示**：手动模式短暂匹配失败时先自动重试，持续失败才提示；重新匹配或滚回已采集画面后清除提示，不再一律要求「放慢滚动」。
- **自动滚动入口**：浮动控制条直接显示手动／自动模式，点击可打开自动滚动与权限设置。打开设置暂停当前采集并保留结果；本次未授权鼠标控制时，设置会说明需在下次开始时申请授权。

## 使用与限制

- Linux 默认手动滚动；在「设置与快捷键 → 权限与长截图」开启「长截图自动向下滚动」并保存，下次开始时授权指针控制。可用性取决于桌面门户提供的能力及实际授权。
- 大面积动画、多个分散动态区域或缺少可靠重叠内容时仍可能无法拼接，建议暂停动画或缩小到需要的正文区域。自动滚动不能补回已跳过的内容。
- 本版未新增拖动采集框底边触发自动滚动的交互；开始前的选区调整行为保持不变。
- macOS 暂不支持长截图；录屏仍为无声视频。Windows/macOS 安装包暂未配置正式开发者签名与公证。

局部动画、静态像素位置、短暂失败恢复、原有表格和侧栏回归及竞态测试通过；紧凑控件渲染、静态检查通过。原生组件及安装包由目标平台 CI 构建、校验，仍需真实页面与设备验收。
