# ScreenPin v0.2.3 — 依赖升级与交互兼容性修复

本次更新升级原生界面、离线 OCR 和构建依赖，并修复鼠标操作被系统取消时可能误提交标注、截图选区或文字选择的问题。

## 下载

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `screenpin-0.2.3-windows-amd64-setup.exe`；免安装版 `screenpin-0.2.3-windows-amd64-portable.zip` |
| macOS 15+ Apple Silicon | `screenpin-0.2.3-darwin-arm64.dmg` |
| macOS 15+ Intel | `screenpin-0.2.3-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `screenpin-0.2.3-linux-amd64.deb`（Ubuntu 22.04 或兼容运行库） |
| Arch Linux x64 | `screenpin-native-0.2.3-1-x86_64.pkg.tar.zst` |
| 其他 Linux x64 | `screenpin-0.2.3-linux-amd64-portable.tar.gz` |

完整包包含离线中英文 OCR 模型与运行时，无需安装 Python。升级前请退出旧实例，并完整替换主程序和配套组件。`SHA256SUMS` 提供七个安装包与便携包的校验值。

## 主要变化

- **离线 OCR**：RapidOCR 升级到 3.10.0；Linux、Windows 和 Apple Silicon macOS 使用 ONNX Runtime 1.31.1。Intel macOS 保留有对应预编译安装包的 ONNX Runtime 1.23.2。
- **原生界面**：MyGo 升级到 0.8.1，同时升级 purego 0.11.3、godbus/dbus 5.2.4 和 x/image 0.47.0。
- **操作取消**：系统取消鼠标捕获时，标注拖动恢复原状态并保留撤销/重做记录；屏幕框选不再误确认；图片选区和 OCR 拖选恢复之前的选择。
- **构建与打包**：PyInstaller 升级到 6.22.3，重新生成 OCR 哈希锁文件；升级四个 GitHub Actions 依赖并保留提交 SHA 固定。预览构建新增完整安装包上传、下载和文件校验。
- **兼容约束**：mpmath 保留 1.3.0，以满足当前 SymPy 的版本约束。

升级组合已通过 Windows、Linux、macOS ARM64 和 Intel 的原生构建与离线 OCR 测试、Go 竞态与静态检查、图片内存回收测试、Arch 打包，以及全部七个产物的上传下载校验。验证细节见 `docs/DEPENDENCY_COMPATIBILITY.md`。

## 平台范围

- macOS 暂不支持长截图；Windows/macOS 安装包尚未配置正式开发者签名与公证。
- 原生 GPU 内存、真实桌面权限和混合 DPI 多显示器交互仍需人工验收，自动化测试不覆盖这些全部场景。
- OCR 选词、框选取字、长截图与资源管理功能继续沿用 v0.2.2 的功能范围。
