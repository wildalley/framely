# Framely · 取景 v0.4.1 — 命令名称与 Linux 安装修复

本版将用户命令统一为 `framely`，补齐 Linux 本地安装、应用菜单和便携包安装入口。

## 主要变化

- Linux 安装提供 `framely` 命令，`screenpin` 继续作为兼容入口，已有快捷键和自启动配置可以继续使用。
- 命令行帮助、开发入口和当前文档统一使用 `framely`，帮助列出截图、长截图、取字、翻译、取色、重复区域和录屏等参数。
- 本地安装脚本备份并原子更新命令链接，应用菜单和安装后启动使用 `framely`；支持覆盖旧文件、旧链接及失效链接。
- 修复 Linux 便携包解压后运行 `./install.sh` 仍寻找旧格式压缩包而无法安装的问题。现在可直接从解压目录安装，保留覆盖安装和卸载能力。
- 发布流程升级到 `actions/download-artifact` 8.0.2，下载产物时执行摘要校验。
- Linux 构建先探测可用的 Ubuntu 镜像，保留 Ubuntu 签名校验，并增加下载重试与安装超时；新增仅检查依赖的轻量 CI 模式，发布提交由 tag 工作流验证，避免重复构建。

## 下载与升级

| 平台 | 附件 |
| --- | --- |
| Windows x64 | `framely-0.4.1-windows-amd64-setup.exe`、`framely-0.4.1-windows-amd64-portable.zip` |
| macOS 15+ Apple Silicon | `framely-0.4.1-darwin-arm64.dmg` |
| macOS 15+ Intel | `framely-0.4.1-darwin-amd64.dmg` |
| Ubuntu/Debian x64 | `framely-0.4.1-linux-amd64.deb` |
| Arch Linux x64 | `framely-0.4.1-1-x86_64.pkg.tar.zst` |
| Linux x64 便携版 | `framely-0.4.1-linux-amd64-portable.tar.gz` |

升级前从托盘退出旧实例，完整安装应用与配套组件。Linux 便携包解压后执行 `./install.sh`，然后从应用菜单或 `framely` 启动；命令目录为 `~/.local/bin`，需要加入 `PATH`。配置目录和桌面/门户应用 ID 延续已有版本，设置与授权保留。

完整包包含采集、录屏/FFmpeg 和离线中英文 OCR 运行时；离线翻译模型在设置中按需下载。`SHA256SUMS` 提供全部七个安装包与便携包的校验值。

## 验证与范围

- 本地 34 项 Python 回归、版本检查和 Linux 构建通过。
- 使用实际生成的安装脚本与编译后的主程序，验证首次安装、覆盖安装、两个命令的版本与帮助、桌面注册和卸载；该安装检查使用轻量组件占位文件。
- 发布工作流在四个平台构建并验证完整运行时，检查七个发布附件后才创建 Release。

平台功能和已知限制延续 [v0.4.0](v0.4.0.md)：macOS 暂不支持长截图，Windows/macOS 尚未配置正式开发者签名与公证。
