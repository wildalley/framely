# Framely · 取景 v0.4.2 — 三端安装路径与旧版迁移

本版修复应用更名后，真实程序、安装目录和组件仍使用 ScreenPin 名称的问题。

- Windows 默认安装到 `%LOCALAPPDATA%\Programs\Framely\Framely.exe`。升级时将注册表记录的旧 `ScreenPin` 目录迁到同级 `Framely`，更新快捷方式和自启动；保留禁用自启动的状态、自定义安装目录和旧目录内的用户文件。
- Linux 真实程序统一为 `framely`：deb 使用 `/opt/framely`，Arch 使用 `/usr/lib/framely`，便携版使用 `~/.local/framely.app`，开发安装使用 `~/.local/bin/framely`。便携升级备份旧应用、更新命令及桌面入口；旧命令和绝对路径只保留兼容链接。
- 三端采集、录屏、FFmpeg、OCR 组件统一为 `framely-*`，完整包拒绝混入旧命名组件。
- 设置、录屏状态和 Linux 共享来源迁到 Linux 的 `~/.config/framely`、Windows 的 `%APPDATA%\Framely`、macOS 的 `~/Library/Application Support/Framely`。已有新设置优先，旧内容备份，不会重复导入已删除的共享授权记录。
- macOS 应用包和程序继续使用 `Framely.app` / `Framely`。系统应用 ID 保持不变，以延续已有权限和密钥。
- 增加独立的三端安装器检查，在完整 OCR/FFmpeg 构建前验证首次安装、旧版迁移、覆盖安装和卸载，减少反复构建。

升级前从托盘退出旧实例，完整安装新应用和组件。Windows 使用安装器执行自动迁移；便携 ZIP 请完整解压到新目录。Linux 便携包解压后执行 `./install.sh`。macOS 将 `Framely.app` 复制到应用程序目录，如仍有早期 `ScreenPin.app` 可移除旧应用副本。

Release 包含 Windows 安装器/便携包、macOS Apple Silicon/Intel DMG、Linux deb/便携包、Arch 包共七个附件及 `SHA256SUMS`。平台功能与限制延续 [v0.4.0](v0.4.0.md)。
